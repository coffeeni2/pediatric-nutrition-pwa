Auto Prescription Draft

เลือก source ที่ต้องการใช้จากตรงนี้ก่อน Generate/Recalculate • ลำดับ Modular Diet: formula/milk โดยดู Ca ก่อน (ไม่เกิน protein/concentration) → protein ที่เหลือ → MCT → LCT → CHO → Ca/Na/K → ± trace element • % energy เป็นค่าเริ่มต้นและระบบปรับสัดส่วน source ได้ • Auto = ระบบปรับได้ • แก้ Amount เอง → Manual • Manual/Locked จะไม่ถูก Recalculate • Maximum / Rounding ยังมีผล

Use in prescription draft

Total 0% • Allocation เป็นค่าเริ่มต้น ไม่ใช่ข้อบังคับ • Diet fat / Modular fat เป็น optional target ของ fat kcal ภายใน source นั้น โดยใช้ LCT×9 + MCT×8.3 • Auto สามารถปรับ % Diet / Milk-Formula / Modular เพื่อให้ Energy และ Protein ใกล้ target ที่สุด • Fat รวมเป้าหมาย ±5% • Minerals เป็นลำดับถัดไป • หลังแก้เองใช้ “Calculate Intake” ซึ่งจะไม่เปลี่ยนปริมาณหรือ rebalance สูตร

Nutrient Recheck

Calculate Intake = ตรวจ nutrient จาก prescription ปัจจุบันเท่านั้น ไม่เปลี่ยน amount, rounding หรือสูตร • Optimize Again เท่านั้นที่อนุญาตให้ระบบปรับสูตร

1. Diet

Amount คือปริมาณจริง • Rounding เลือกทีละ 1 / ทีละ 5 / ทศนิยม 1 ตำแหน่ง • Lock = ห้าม Auto เปลี่ยน • Maximum เป็นเพดาน optional

2. Milk / Formula

ใช้ mL หรือกล่อง 180/200/225 mL • รองรับ fortified milk/formula ด้วย maltodextrin, oil, whey, casein หรือรายการอื่นจาก Custom DB

3. Modular Diet Builder

เลือกส่วนประกอบและจำนวนจริง • เติมน้ำจนครบ final volume • กำหนด mL/feed × feeds/day

Components by nutrient role

เลือก source ในแต่ละ role ก่อน แล้วใช้ Calculate modular sequence: formula/milk → remaining protein → MCT → LCT → CHO → Ca/Na/K. Tube feeding จะเตือน rice concentration >8 g/100 mL และ Auto rice จำกัดไม่เกิน 9 g/100 mL
