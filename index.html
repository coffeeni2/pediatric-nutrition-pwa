Auto Prescription Draft

ลำดับการ optimize: Energy + Protein → Fat ±5% → Minerals • % energy เป็นค่าเริ่มต้นและระบบปรับสัดส่วน source ได้ • Auto = ระบบปรับได้ • แก้ Amount เอง → Manual • Manual/Locked จะไม่ถูก Recalculate • Maximum / Rounding ยังมีผล

Total 0% • Allocation เป็นค่าเริ่มต้น ไม่ใช่ข้อบังคับ • Diet fat / Modular fat เป็น optional target ของ fat kcal ภายใน source นั้น โดยใช้ LCT×9 + MCT×8.3 • Auto สามารถปรับ % Diet / Milk-Formula / Modular เพื่อให้ Energy และ Protein ใกล้ target ที่สุด • Fat รวมเป้าหมาย ±5% • Minerals เป็นลำดับถัดไป • หลังแก้เองใช้ “Calculate current values — no recalc”

Diet structure
เมื่อ Use Diet เปิด ระบบจะพยายามคงกลุ่มอาหารพื้นฐานไว้ ไม่ให้ optimizer ลดจนเป็น 0 เพียงเพื่อให้ตัวเลขลง target

Structure บังคับเฉพาะการมีอย่างน้อย 1 serving-step ของกลุ่มที่เลือก; Amount ที่เป็น Manual/Locked ยังคงมีสิทธิ์เหนือ optimizer. ถ้าปิด Use structure ระบบจะ optimize ตาม nutrient targets อย่างเดียว.

1. Diet

Amount คือปริมาณจริง • Rounding เลือกทีละ 1 / ทีละ 5 / ทศนิยม 1 ตำแหน่ง • Lock = ห้าม Auto เปลี่ยน • Maximum เป็นเพดาน optional

2. Milk / Formula

ใช้ mL หรือกล่อง 180/200/225 mL • รองรับ fortified milk/formula ด้วย maltodextrin, oil, whey, casein หรือรายการอื่นจาก Custom DB

3. Modular Diet Builder

เลือกส่วนประกอบและจำนวนจริง • เติมน้ำจนครบ final volume • กำหนด mL/feed × feeds/day
